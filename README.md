## 📑 О проекте

**KiloStorm** — это сочетание экшен-игры и клавиатурного тренажера. Вы управляете защитной башней, отражая волны наступающих врагов с помощью скорости и точности вашей печати. 

Главный акцент в проекте сделан на **сбор и визуализацию глубокой аналитики**, чтобы помочь игрокам улучшать свои навыки печати и отслеживать динамику.

> 🎯 **Игровой процесс:**  
> Вы появляетесь на локации, в центре которой расположена башня. Навстречу башне идут волны врагов. Над каждым врагом отображается слово — введите его без ошибок, чтобы уничтожить врага.

## 🎮 Игровые режимы

В игре представлены режимы, рассчитанные на разный уровень подготовки:

| Режим | Описание | Кому подойдет |
| :--- | :--- | :--- |
| 🛡️ **Выживание** | Пройдите **10 этапов** за ограниченное время. Время строго фиксировано, задача — успеть уничтожить всех врагов. | Отлично подходит для **новичков** и тех, кто печатает со средней или низкой скоростью. |
| ♾️ **Бесконечная игра** | Забег на выносливость без ограничений по времени. Волны врагов и сложность возрастают постепенно. | Идеально для игроков со скоростью печати **выше среднего**, желающих проверить предел своих возможностей. |

## ✨ Основные особенности

- ⌨️ **Глубокая аналитика:** Подробная статистика по точности (Accuracy), скорости (WPM/CPM) и частоте ошибок.
- 🏰 **Динамичный геймплей:** Визуальный азарт и драйв классической Tower Defense с механикой слепого ввода.
- 📈 **Прогрессия:** Отслеживайте свой прогресс от игры к игре.

## 🚀 Установка и запуск

### Системные требования (Минимальные)
* **ОС:** Windows 10 (64-разрядная)
* **Процессор:** Intel Core i5-4590 или аналогичный
* **Оперативная память:** 8 GB ОЗУ
* **Видеокарта:** NVIDIA GeForce GTX 1050 или аналогичная
* **Место на диске:** 200 MB

### Шаги по установке

1. Скачайте архив последней актуальной версии игры из раздела **Releases**.
2. Распакуйте архив в удобную для вас папку.
3. Запустите исполняемый файл `KiloStorm.exe`.
